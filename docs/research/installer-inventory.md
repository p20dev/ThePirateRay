# Original installer-stick inventory

Status: acquired, hashed, and preserved in private evidence snapshot commit
`50e589c`.

The read-only source contains an EZCAD2 2.14.16 installation configured for a
JPT 100 W E2/M7 source. Separate 110 mm and 300 mm configurations are present.

Observed evidence classes include:

- per-lens `markcfg7` files;
- `CoeFile.cfg`, `EZCAD.CFG`, parameter libraries, and USB logs;
- screenshots of field, laser-control, port, red-pointer, workspace, and rotary
  settings;
- EZCAD executables, plugins, DLLs, driver installer material, and a manual;
- LightBurn `.clb` material libraries for multiple lens sizes.

All originals and exact source locators belong in PrivateStash. This public
inventory intentionally omits serial numbers, Drive identifiers, executable
copies, and manual copies.

See the [sanitized 110/300 comparison](config-comparison.md) and
[`evidence/public-installer-configs.jsonl`](../../evidence/public-installer-configs.jsonl)
for traceable public hashes.
